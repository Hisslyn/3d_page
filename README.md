# NEXUS

An interactive 3D cosmic landing page built with Three.js. Features a solar system of clickable "worlds", drag-to-orbit controls, smooth zoom animations, and a custom cursor — all in a single HTML file with no build step.

## Demo

Open `nexus-landing.html` directly in a browser.

## Features

- 3D planetary system rendered with Three.js
- Drag to orbit, scroll to zoom, click a world to enter
- Animated title reveal and entrance transitions
- Film grain overlay and atmospheric vignette
- Custom cursor with hover states
- Fully responsive (touch-friendly on mobile)

## Tech

- [Three.js r128](https://threejs.org/) — 3D rendering
- [Syne](https://fonts.google.com/specimen/Syne) + [Space Mono](https://fonts.google.com/specimen/Space+Mono) — typography
- Vanilla JS / CSS — no framework, no build tools
